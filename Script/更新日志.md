## 0.26.21 实例ID改注册名

- 没什么特别的，实例ID去掉了，之前一串数字，只有系统内部认得出，现在统一改为可读的注册名了。

### 更新内容

- 角色也走上注册名了：**角色的注册名 = `Char/原型类型`**（`Char/人类`），像 UI 的 `UI/` 一样带自己的根前缀
  - 构造只要**原型名 + 身份**（原来那个"名称"参数去掉了——名字由注册名给）
  - 名字与身份是两回事：**名字**跟着实例（`@Char/人类` 一直指它），**身份**是"现在谁演这个位子"（`CharSys.identities`，可改绑；状态名仍可写 `"状态名@身份"`）
- **实例 ID 彻底退场**：基类里的 `ID` 删掉了，指令 `@数字`、配置里的实例 ID、消息节点用 ID 的地方全改成注册名
- 注册名系统
  - `register` 现在**返回真正用上的名字**（重名让路由一个开关管：`dedup`）——角色同名自动排到 `Char/人类_2`
  - 让路算号改成**占名计数表**，不再遍历所有登记名（注册对象只会越来越多，遍历会越跑越慢）
- 验证：Godot 全项目解析 clean；跑起来无 warning（消息节点名、UI 子元素名都照旧）


- **角色**（`Script/Character/Character.gd`、`CharacterSystem.gd`）：`_init(原型, 身份="")`，
  注册名 `Char/原型名`、重名让路加后缀；`_we` 由"ID → 实例"改成"**注册名 → 实例**"，
  `Character.get_("Char/人类")` 按名取（取不到给 null，不再靠 `_we[id]` 直接下标炸）。
- **注册名系统**（`Script/System/RegSystem.gd`）：`register(obj, want, dedup := false) -> String`——返回用上的名字。
  `dedup` 时走 `_claim`：按 `_used_count`（基名 → 已发出去几个）算下一个号，登记表只在"这名字被人手写登记过"时兜底；
  **号只增不减**（名字不回收——回收会让后来者顶着旧名字，而消息节点名是按名字拼的，等于串消息）。
  UI 那条仍走 `unique(want, taken)`：建树时父元素自己还没登记，只能按"已有的兄弟名"判。
- **消息系统**（`MessageHub.gd`）：`_format_character` / `_format_ui` 都用注册名
  （`CHAR->Char/人类->STATUS->Tick->satisfied`、`UI->UI/MiniHUD->open`）；
  指令解析 `CommandParser._instance_of` 只认 `@self` / `@host` / `@注册名`（数字那支删了）。
- **文档**：把 30 处"实例 ID 也认 / 老配置退回 ID / `self.ID`"改准（`设计文档.md`、`UI.md`、`System.md`、各处注释）。
- 验证：探针确认 `Char/人类` / `Char/人类_2` / `Char/兔子_2` 与计数表、消息节点名、UI 子元素名（不该加后缀时没加）、
  "同预设开两次复用同一个 UI 名"都正常；扫描 + 运行 clean。
