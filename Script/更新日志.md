# 更新日志

## 0.26.3 UI拖动

- 按键按下是一个持续性动作，因此down不会在每帧触发"满足=>不满足"
    - 然而，拖动需要判断长按，而拖动是每帧更新的，不会每帧触发”满足“意味着只会在第一次被拖动
- 因此，实现了Tick状态，每帧触发一次"满足=>不满足"
    - 之前的Tick没有这个设定，而是始终满足，现在这个状态被AlwaysSatisfied取代了
- 如此，拖动可以用”按键按下“+”Tick“来实现每帧拖动
- 考虑到拖动只在鼠标移动时有效，因此新增了Pointer Move状态，用于检测鼠标移动
- 如此，拖动可以用”按键按下“+”Pointer Move“来实现每帧拖动

### 新增 · 输入状态统一（Input）
- `Config/Character/Status/StatusPreset_Input.gd`：新增输入状态配置，合并指针与键盘按键状态（Mouse Left First Down/Pointer Move/Mouse Left Up/Right/Up/Left/Down/Submit）。
- `Config/Character/SystemShortcut/SystemShortcutPreset_Input.gd`：新增输入快捷配置，指针状态满足即执行 `PointDetect.*`。

### 修改
- `Config/Character/Archetype/Archetype_System.gd`：SYS 增加"其它"包（AlwaysSatisfied 状态），指针状态由 `Pointer Hold` 更名为 `Pointer Move`。
- `Config/Character/Status/StatusPreset_Basic.gd`：新增 `AlwaysSatisfied` 常真状态。
- `Config/Character/Status/StatusPreset_Move.gd`：移除 Right/Up/Left/Down 按键状态（迁移至 StatusPreset_Input）。
- `Config/Character/Status/StatusPreset_Time.gd`：`Tick` 状态补充 `time: [["Tick", "Advance"]]` 监听配置。
- `Config/Character/SkillPreset_Basic.gd`：Free Fall/Air Drag/Ground Friction 的依赖状态由 `Tick@SYS` 改为 `AlwaysSatisfied@SYS`。
- `Script/Utils/Enums.gd`：`KeyStatus` 移除 `UP`（由 Down 或其 Unsatisfied 替代），新增 `POINTER_MOVE`。
- `Script/Message/MessageHub.gd`：新增输入域的 `send_pointer_move`/`listen_pointer_move`，移除未用的 `send_key_up`/`listen_key_up`。
- `Script/Input/InputSystem.gd`：鼠标移动时发 `Msg.send_pointer_move()`。
- `Script/Character/Status/StatusPreset.gd`：Key 监听新增 `POINTER_MOVE` 分支，time 监听新增 `Tick`，并清理已废弃的 Behavior 监听注释代码。
- `Script/Character/Collision/Collisions.gd`：`attach_collisions` 循环变量补类型标注 `CollisionPreset`。


### 删除
- `Config/Character/Status/StatusPreset_Pointer.gd`：删除旧指针状态配置（由 `StatusPreset_Input.gd` 取代）。
- `Config/Character/SystemShortcut/SystemShortcutPreset_Pointer.gd`：删除旧指针快捷配置（由 `SystemShortcutPreset_Input.gd` 取代）。
