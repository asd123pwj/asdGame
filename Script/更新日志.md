- **新增 FPS 显示**（`UIPreset_FPS`，按 **F3** 开关）：屏幕左上角一小块，显示当前帧率。
  - **不新增元素、也不连引擎信号**：走项目自己"**每帧 = 状态 + 快捷**"那条路——SYS 上一条 **Tick 快捷**
    调 `UIPreset_FPS.tick()`；那扇 UI 没开着时它第一句就 `return`（按登记名查不到）⇒ 常驻也几乎零成本。
  - **只在"取整变了"时才真刷**：帧率是滚动平均、每帧都动一点，不判一下就是每帧重排版；
    值的来源只有一处（文字那条 `content_cmd = UIPreset_FPS.text()`），`tick()` 只管"要不要刷 / 刷一下"。
