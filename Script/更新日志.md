# 更新日志
## 0.26.41 地图查看UI

- 画了点UI，修复了点BUG
- 然后实现了一个地图查看UI
  - 可以查看某层某坐标的地图块，以及子层地图块拆解
  - 子层地图包括地面，地面的伪3D，植物，家具四层，暂时只实现这四层
  - 查看位置可以编辑坐标，也可以根据鼠标位置实时查看。
  - 不过暂时还有点查看问题，因为地图是随机取的，一个类型有多个变种，显示的时候变种没显示正确






- **新增"此格瓦片"窗口**（`UIPreset_MapCell`）：看鼠标所在那一格的四层瓦片叠起来的样子（图是**现算出来的
  `Texture2D`**，所以 `UI_Image` 也认现成的纹理了），下面一行行写清那四层分别是什么，
  再给 `x` / `y` / `layer_id` 三个输入框现场改；可选项**实时监控**（按住指针动就跟着换格）、
  按住空白拖动、右键管理菜单。
  - **"不给 `position`"是有意的**：实时监控每次刷新都走一次 `open` 的摆位（CONFIG 策略），
    写死坐标会被拽回去、拖动白拖；不写 = 显示在哪就保持在哪。
  - `free` 定位的元素**必须给死 `size`**：没有宽度上限的自由文本会被压成 1px 宽、字竖着排成一列（实测）。
- **输入框那根光标终于看得见了**：引擎默认主题是给**深色**底配的（`caret_color` 接近白），画在浅色竹纸上等于没有。
  而它**不是图、是颜色**（LineEdit / TextEdit 只有"颜色 + 宽度"两个主题项，**没有放光标图的槽**）——
  所以给成深色 + 2px 宽；顺手把多行框"当前行"的底色（默认深灰）与选中底色也压成适合浅底的样子。
  - 这几支色连同"默认字色"一起收进了 `QName`：**同一个值多处用 ⇒ 只留一处**
    （`UI_View._row` 原来就抄过一份和默认字色一模一样的字面值，改全局改不到它）。
- **输入框终于能按住拖动选字了**：以前只能全选（三击 / Ctrl+A）。根因是两层：
  - ① `PointerDetect.key`（HOLD 事件的派发入口）**开头无条件先收一遍编辑**，而 HOLD 按住期间**每帧都派发**
    ⇒ 每帧都把"正在编辑谁"清掉，接着那次派发又当成"刚进来"；
  - ② "刚进来"时那句 `select_all()` 于是**每帧执行一次**，用户拖出来的选区每帧被清成全选。
  - 现在：`PointerDetect.key` 只在"**刚按下那一下**"、且"**点的不是正在编辑的那个元素**"时才收编辑
    （"刚按下"那一发信号由 `InputSys.take_mouse_pressed` 给，**取一次就清**——快捷派发不是同步的，
    用帧号判断会漏）；"进来就全选"直接删了（它挂在逐帧指令上，本来最多只在第一帧生效，等于没有）。
- **"文字被裁"和"两行框莫名出滚动条"是同一个坑**：底图铺上九宫格之后暴露出来的——
  `StyleBoxTexture` 的 `content_margin` 默认是 **-1**，而框架里几处**自己算尺寸**的地方读的就是它
  ⇒ padding 被当成负数漏掉（实测：多行框两行的高度算成 52，正确是 86）。
  现在统一走 `UIBase._style_pad`：`content_margin < 0` 就退回真正生效的 `get_margin()`（= 九宫格边距）。
- **富文本浮窗"延时打开之后关不掉"**：以前靠 `Msg.send_cmd` 的**返回值**记"这个元素开出了哪几扇浮窗"，
  而延时执行（`TimeSys.after`）时那条路根本拿不到结果 ⇒ 记录一直是空的，自然关不掉。
  改成**不另记表**：那些浮窗就是**挂在 label 下面的子 UI**，收的时候直接看 `label.children`（一份数据一处真相）；
  判据也改成"**悬停的那段 meta 变了**（含离开链接 ⇒ null）就先收掉上一扇"（这就是"同时只留一扇"）。
- **展示文本框暂时不可选中**：引擎不给 RichTextLabel 的 Ctrl+C（不像 LineEdit / TextEdit 自带剪贴板那一套），
  光能拖蓝一片、复制不了反而奇怪。开关（`UI_Label` 的 `config["selectable"]`）留着、默认关，
  等真做"选中 + 复制"（输入层拦 Ctrl+C → `get_selected_text()` → 写剪贴板）时打开即可。
- **两张竹卷轴的底图接上了**（用户画的 64×64、四角 16）：展示文本框 = 横版、输入框 = 竖版；
  中段**平铺**（竹纹有细节，拉伸会走形）。`UI_Base` 也补了"元素级九宫格默认"，好让"换过图的元素"
  在没写边距 / 填充时按自己那张图的规格切。
- **测试 UI 全删**：`UIPreset_Test` / `UIPreset_MetaTest` / `UIPreset_Fold`（连文件）、`UIPreset_Basic` 里的 `MiniHUD`、
  `test.gd` 的 `ui_test()`、状态层那两条 J / K 测试绑定 —— 之前只是注释停用，这次确认效果没问题、删干净。
  （顺带重建了引擎的全局类缓存：不处理的话每次启动都报三条"文件不存在"。）
- **顺带把重复收了一遍**：
  - 底图三键（`background` + `background_slice` + `background_stretch`）收成 `UIPreset_Basic.bg()`，
    不写边距 / 填充就是"**竹图那套规格**"（`SysCfg.ui_bamboo_slice / ui_bamboo_stretch`）；
  - `UIPreset_View` 里那 4 个 `*_SLICE / *_STRETCH` 常量删掉（本来就与全局那组同值）；
  - `UI_View._row` 不再自己抄默认字色、也不再重复写 `max_chars`（`add_child_element` 的覆写本来就补）；
  - `UIPreset_MapCell` 里"`free` + `position` + `size`"那套摆位写了 11 遍 ⇒ 收成 `_at` / `_abs`；
  - 菜单那三个开关式按钮（关闭 / 缩放 / 改尺寸）收成一个模板 `UIPreset_Basic.toggle_item()`；
  - 文档里拿 `MiniHUD` 当例子的地方统一换成真实存在的 `RoleData`，删掉的文件剩下的失效引用一并清理。
