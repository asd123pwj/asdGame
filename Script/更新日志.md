# 更新日志

## 0.26.15 UI交互：失焦关闭 

- 点击菜单外面，菜单自动关闭，即失焦关闭。
- 几个版本前就实现好了，不过之前有问题，点击时移动鼠标会关闭
  - 我一直没捋清，因为我觉得他只在按下时发送事件，不应该在长按未发送事件时关闭
- 刚刚审阅了一下，发现是指针移动的交互关的，把指针移动挪外边就好了。

### 改动 · 指针事件收归 PointerDetect（PointerDetect.gd / InputSystem.gd / Archetype_System.gd）

- **派发分两类**（文件头也这么写了）：① 指针自己的 `Pointer Enter` / `Pointer Exit` / `Pointer Move` 由 `_process` 直接派发——它们不是状态，不该占状态层的配置；② 按键类事件（press/hold/release）仍走状态层 → 快捷指令 `PointerDetect.key "<状态名>"`。
- **`Pointer Move` 由位移驱动**：`_process` 里 `InputSys.mouse_delta != Vector2.ZERO` 就派发给 hover 的 UI（和 enter/exit 同一个写法）。位移由 `_input` 累计、帧末清零，所以这里看到的正是"这一帧动了没有"。
  - 语义变化：以前是"**按住某键时的移动**才算 Pointer Move"（`InputSystem._input` 里 `keys_holding` 非空才发），现在只要指针动了就算——要表达"拖拽中的移动"直接用 `Mouse Left` 状态本身（拖拽/缩放走 `AutoSys`，与指针在哪无关）。
- **消息层那条通路整条删掉**：`Msg.send_pointer_move` / `listen_pointer_move`、`StatusPreset` 里 `POINTER_MOVE` 的监听分支、`Archetype_System` 里 `Pointer Move` 那个状态与快捷——都没有使用者了。`Enums.KeyStatus.POINTER_MOVE` 保留（删中间值会让已存盘 json 里的枚举整数串位），注释改成"由 PointerDetect 直接派发"。
- `InputSystem._input` 现在只累计位移与位置，**一个字都不发**。

### 改动 · 命中检测一帧一次 + 失焦判定晚于派发（PointerDetect.gd / InputSystem.gd）

- 刷新 hover 从 Tick 的一条快捷指令挪进 `InputSys._process`，并 **`update_targets` → `_process(delta)`**：这样它**先于按键派发**（派发用的就是本帧刚算出来的 hover），并且一帧只有这一次（Tick 那条快捷已注释掉）。
- **失焦关闭不再在 `key()` 里"补刷一次命中再判"**：`key()` 只置 `_blur_pending`，判定放在 `_process` 的尾巴上做（用的就是刚算出来的 hover）。两个理由：① 判定必须晚于派发——菜单是这次派发里刚 open 出来的，拿"上次刷新的 hover"判会把它当成"指针在外面"当场关掉；② 命中检测一帧只该有一次，多刷一遍既白跑、又会让 enter/exit 在同帧里派发两次。
- 每帧顺序固定为：`InputSys._process`（刷新命中 → 派发 HOLD）→ `TimeSys._process`（Tick）→ `AutoSys._process`。
- `close_blur_ui` 里"尺寸为 0 先跳过"保留，但降级成第二道保险（判定已经晚于派发，那时布局早跑完了）。

### 修正 · 指令写错时不再静默（Script/UI/Interact/）

- `UIInteract.switch_value`：`config` 里没有这个键时警告——以前会**静默新建一个键**，把 `events` 写成 `event` 就什么反应都没有。
- `UIInteract.close <宿主> <预设名>`：预设名不存在时警告（"预设存在但没开过"仍是静默幂等，那是正当用法）。
- 各交互里 `if ui == null: return` 那几句不用补警告：`_as_ui`（交互组基类）已经替它们报了（"target 为空 / 未 build"）。

### 顺手 · 改名与文档对齐

- `AutoSys.update` → `_process` 的引用（`Auto.md` / `AutoSystem.gd` / `Drag` / `Rescale` 的"被谁用"）全部对齐；驱动者也从"Tick 快捷指令"改成"`Sys._process` 直接调"。
- `PointerDetect.update_targets` 的引用（`Input.md` / `UI.md` / `UIBase.gd` / `InputSystem.gd`）全部对齐；`_hit_in` 里 `get_meta(...) as UIBase` 按项目惯例补了 `@warning_ignore("unsafe_cast")`。

### 验证

- 探针实测（跑完即删）：
  - `Pointer Move`：给 `MiniHUD/Title` 挂一条 `Pointer Move → set_content`，位移非 0 时内容变、位移为 0 时不变；
  - 失焦关闭：右键开菜单 → 可见；指针移到屏幕外再派发一次 → 下一帧关掉；**再开一次仍然可见、且复用同一实例**（旧写法会当场被自己关掉）；
  - 写错时报警告：`switch_value(hud, "event", 1)`、`close(hud, "NoSuchPreset")` 两条都能在日志里看到。
- 复跑（`--headless --quit-after`）无脚本错误；lint 干净。
