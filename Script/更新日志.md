# 更新日志
## 0.26.32 背包网格UI排布

- 拖动Resize会对里面的等大小的网格进行排布。
- 例如，12个格子，有3格宽时，排4行，4格宽排3行
- 此外，由于UI_Scroll和UI_Panel高度重合，去掉了UI_Scroll

### 更新内容

- `UI_Panel`：
  - config 新增 `cell`（等大格子 = [宽, 高]）与 `gap`（最小间距，不写 = 4）：格子等大、**列数由内容区宽度决定**
    （能塞几列就几列），行数 = 个数 / 列数（向上取整）；剩余不足一格的空位写成
    `clampf(摊出来的间距, 最小间距, 一格的大小)` ⇒ 拖到"不够一列"时看到的是**间距变宽**，撑到能多塞一列才换行；
  - 排不下（行数 × 格子 + 间距 > 视口高）⇒ 内容盒撑到实际需要的高度 ⇒ 面板的滚动条出现（滚着看）。
    **判据要用滚动容器的视口高**，不能用内容盒自己的高——它被撑高后自己就等于那个高，拿它比会把刚设的最小高又清成 0
    （实测：滚动条闪一下就没、怎么都滚不动）；
  - 三种排法收成**一个入口** `_layout_grid()`（竖排 / `matrix` / `cell` 分派），摆格子共用 `_place_cell()`；文件头补上排法说明。
- `UI_Scroll.gd`（**删除**，−98 行）：内容盒外的滚动容器、`panel` 底图槽、`Overlay` 都与 `UI_Panel` 重复。
- `UIPreset_Basic`：新增 `text_item(兜底文本)` —— "会滚文本"的正文子元素（`content_cmd` 读外壳的 `content`，
  `wrap: true` 让文字照面板给到的宽折行、只报该多高）；MiniHUD 的 `Info` 由 `UI_Scroll` 换成 `UI_Panel` + `text_item`。
- `UIPreset_Test`：`TestShow` 同上（换成 `UI_Panel` + `text_item`）；新增 `BagTest` 演示窗（12 格）；文件头补 `BagTest` 说明。
- `test.gd`：`BagTest` 并进"带手柄窗口"的开启循环；MiniHUD/Info 改完内容后 `refresh("content")` → **`refresh_tree()`**。
- `UI_Editor._refresh_owner`：`ui.refresh()` → **`ui.refresh_tree()`** —— 改的多半是**外壳**的配置，而读它的常常是**子元素**
  （正文写 `content_cmd = "@self.parent.config.content"`），只刷外壳那一层它们还停在上一次的内容。
- 文档同步：`UI.md`（元素表 / 目录树 / `content` 说明 / 背景槽表 / MiniHUD 示例）、`设计文档.md`、
  `UIBase` 与 `UIInteract_OpenClose` 里指向 `UI_Scroll` 的注释。
- 实测：等大网格 260×320 ⇒ 3 列 4 行（无滚动条），拖宽 +80 ⇒ 4 列 3 行，拖小 ⇒ 出滚动条、滚到 400 后格子跟着移；
  MiniHUD/Info `304×120`、正文 40 行、可滚 856；TestShow `260×140`、正文 `244×24`；
  写外壳 `content` 之后的三条刷新路径（`refresh_tree` / `UISys.refresh_all` / 编辑器 `_refresh_owner`）正文都跟着变 ✅
