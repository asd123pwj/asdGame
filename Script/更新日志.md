# 更新日志

## 0.26.2 UI前置准备

- 添加UI系统，
    - UI系统需要读取鼠标输入来判断按下，关闭
- 因此添加系统角色，利用系统角色读取输入状态
    - 受到输入后需要执行拖动
- 因此实现SystemShortcut，类似skills和interact，但执行的是指令
    - 其它角色也有监听系统输入的需求，没必要重复监听一个东西，直接套用系统状态即可
- 因此添加unique_name，用于标识角色
    - 借助unique_name可以定位角色，因此消息传递也可以用unique_name来定位
- 因此消息传递增加resolve_target，用于解析状态的真实角色，即Right@SYS为监听SYS角色的Right状态
    - 这个还有一个好处，敌人可以用Enemy角色，玩家可以用player角色，快速绑定与切换角色对象

### 新增 · 系统快捷（SystemShortcut）
- `Script/Character/SystemShortcut/SystemShortcutPreset.gd`：新增系统快捷预设，监听依赖状态 satisfied 后直接执行指令串（Interaction 的轻量版）。
- `Script/Character/SystemShortcut/SystemShortcuts.gd`：新增角色系统快捷集合（装/卸/查，装发 add、卸发 remove）。
- `Script/Character/SystemShortcut/SystemShortcut.md`：新增系统快捷设计文档。
- `Config/Character/SystemShortcut/SystemShortcutPreset_Basic.gd`：新增系统快捷配置模板（空 values）。
- `Config/Character/SystemShortcut/SystemShortcutPreset_Pointer.gd`：新增指针快捷配置，指针状态满足即执行 `PointDetect.*`。

### 新增 · 指针检测
- `Script/Input/PointDetect.gd`：新增指针目标检测类，只提供执行函数（pointer_down/move/up、submit）并按需 `update_targets()`，不监听按键、不每帧计算。
- `Config/Character/Status/StatusPreset_Pointer.gd`：新增指针按键状态（Pointer Down/Hold/Up、Submit）。
- `Config/Character/Archetype/Archetype_System.gd`：新增 SYS 及"输入监控/指针监控/时间周期"包配置。
- `Script/UI/UiSystem.gd`：新增 UI 管理脚本（持 CanvasLayer 根与 UI 集合，按 UIPreset 挂载/移除并发消息）。
- `Script/UI/UIPreset.gd`：新增 UI 预设（name + ui_name + config，按 ui_name 实例化 UIBase）。
- `Script/UI/UI/UI_Panel.gd`：新增示例 UI 元素（面板 + 文本框/按钮/滚动条）。
- `Script/UI/UI.md`：新增 UI 系统设计文档（替代被删的 `UI设计.md`）。

### 新增 · 独特角色定向
- `CharSys` 新增 `unique` 字典与 `bind_unique`/`get_by_unique`，支持按 unique_name 定向角色。
- `Msg` 全域支持 `名字@unique_name` 语法：`_resolve_target` 统一解析，`_format_character` 用 `unique_name`（空则退化为 ID）作角色标识。
