# 更新日志

## 0.26.6 UI原子化与交互指令化

- 以前一些需求涉及的比较多，偶尔会在一个版本里面东改改西改改，脑子还能勉强记得基本要做什么
    - 这用上了AI，经常出现这种改一堆的情况，脑子已经跟不上了，改完忘记了最初要做什么
    - 尤其是最近在并行开几个项目，虽然都是AI在跑，但是脑子不太够用
    - 什么时候财务自由就好了，就可以专心做游戏了
- 这个版本大致是把UI交互给指令化，按下/长按/释放/移动，四个类型的交互
    - 举例来说，关闭按钮实际上是一个文本UI，配上一个按下=>关闭，或是释放=>关闭
    - 拖动则是移动=>UI移动
- 此外把之前的UI拆的更加原子化，之前AI做了个示例，把一些UI捆绑在一个UIBase里，现在拆开了，改为用配置文件来组装
- 把按键down/first down/first up改为了hold/press/release，改个名称
- 好像把所有按键交互改为了用我自己写的输入系统，而不是Button.press这种，应该是这个版本，不然就是上个版本


### 新增 · UI 交互改为"事件→指令"，元素拆为原子子类
- 说明：UI 不再用 `draggable/closeable/scalable/submittable` 等开关字段，改为"事件→指令"——元素 config 按 `press/move/release/submit` 事件键各配一条指令串，事件发生即发送。指令里 `$parent`(挂载对象)/`$self`(自身) 在发送前替换为实例（`$@ID`）。一个 UI 由根元素 + `children` 配置组装成树。

### 修改
- `Script/UI/UI/UIBase.gd`：移除 `draggable/closeable/scalable/submittable/track_id` 与 `_dragging/_drag_offset/MIN_SIZE/close/fade_to` 等开关与方法；新增 `content`(显示内容)、`parent`(挂载对象)、`children`(子元素)；`on_pointer_down/up` 更名 `on_pointer_press/release`；`build()` 改为"生成控件 → 应用配置 → refresh → 组装 `config["children"]` 子元素"；新增 `set_content`(改内容并刷新)、`_content_box`(子元素挂载点，容器类覆写)；`_fire` 统一为"查事件键 → 发指令"（未配置不发，无默认回退）。
- `Script/UI/UIInteract.gd`（新）：UI 交互指令宿主静态类。`resolve_cmd` 解析 `$self`/`$parent` 链式占位符（`$parent.parent` 任意级，级别不足警告并降级）；`_climb_parent` 向上爬 parent；交互实现 `close/open/drag/fade_to/set_content` 全部为**纯副作用 `-> void`**（不返回值，故经指令调用不会在结果数组里多套一层）；`_as_ui` 只做校验——target 为空或目标尚未 `build()` 时 `push_warning` 指明是哪个指令，不再静默 return。
- `Script/UI/UI/UI_Label.gd`（新）：文本元素，`content` 即显示文本；配 `press` 指令即"按钮"、配 `move` 即"拖动手柄"，无需单独的 Button 类。
- `Script/UI/UI/UI_Image.gd`（新）：图片元素，`content` 为纹理路径，`set_content(新路径)` 即改图。
- `Script/UI/UI/UI_Scroll.gd`（新）：滚动容器，`content` 为多行文本，`set_content` 即改展示；`_apply_config` 内层文本宽度略小于滚动区以便换行滚动。
- `Script/UI/UI/UI_Panel.gd`：简化为"面板容器"——只生成 `PanelContainer + MarginContainer + VBoxContainer` 外观，标题/关闭按钮/滚动内容等全部改由 `config["children"]` 组装；`_content_box()` 返回内部竖排容器。
- `Script/UI/UIPreset.gd`：抽出静态工厂 `create_element(element_name, ui_name, element_config)`，根 UI 与子元素共用；`_get_ui_by_name` 改调它。
- `Script/UI/UiSystem.gd`：`add_ui`/`remove_ui` 改为登记/摘除**整棵 UI 树**——新增 `_register_tree`(根用原名、子元素用 "根名/子名") 与 `_collect_tree`，子元素也进 `uis`，PointDetect 才能把指针命中派发到具体子元素（如关闭按钮）；移除时子控件随根控件一并释放。
- `Script/Input/PointDetect.gd`：`pointer_down/up` 更名 `pointer_press/release`（同步改 `on_pointer_press/release`）；`_ui_at` 命中判定由 `control.visible` 改为 `control.is_visible_in_tree()`，使父 UI 关闭后子元素不再可命中。
- `Script/Message/MessageHub.gd`：按键消息全面更名——`send_key_down/first_down/first_up` → `send_key_hold/press/release`，`listen_key_down/first_down/first_up` → `listen_key_hold/press/release`；删除 `send_cmd0`/`send_cmd00`（返回结果不再多套一层，取值直接 `send_cmd(...)[0]`）。
- `Script/Utils/Enums.gd`：`KeyStatus` 枚举更名——`DOWN→HOLD`、`FIRST_DOWN→PRESS`、`FIRST_UP→RELEASE`（取消注释掉的 `UP` 说明）。
- `Script/Input/InputSystem.gd`：`keys_downing` → `keys_holding`；`_process` 每帧发 `send_key_hold`；`_send_key_status` 按下发 `send_key_press`、抬头发 `send_key_release`。
- `Script/Input/InputCombo.gd`：组合键监听更名 `first_down/down/first_up` → `press/hold/release`；`_check_checkWithFirstDown` → `_check_checkWithPress`；组合匹配时整体发 `send_key_press`、释放发 `send_key_release`。
