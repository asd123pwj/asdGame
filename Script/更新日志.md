# 更新日志
## 0.26.35 菜单功能修正

- 修复已有关闭按钮时，右键菜单会打开第二个关闭按钮的错误
- 修复等比缩放后，浮窗位置错误，拖动速度错误，改尺寸拖动错误
- 移除size ratio，现在的等比缩放和改尺寸配合的非常好


修改简述：

- Config/UI/UIPreset_View.gd（新增）：**角色数据看板**预设——面板尺寸在预设里自己算（`_panel_size()` = `UISys.screen_size() × 0.75`）、`open_at: OpenAt.CENTER`，按 2 行 3 列矩阵摆六个一览；`CELL_CHARS` 按格宽反推每栏字数、每格 `margin` 4
- Config/UI/UIPreset_Status / Attr / Interaction / Skill / Shortcut / Archetype.gd（删除）：六个独立一览预设取消，外壳统一并入 UIPreset_View 的矩阵格子
- Config/SystemConfig.gd：新增全局底图 `ui_background` / `ui_background_slice` 与全局默认字色 `ui_font_color_default`（浅底深字，一处生效）
- Config/UI/UIPreset_Basic.gd：`close_item()` 的元素名 `Close` → `CloseButton`（**必须与预设同名**，菜单的"启用/移除关闭按钮"才能复用窗口自带的那个，否则会再建一份）
- Config/UI/UIPreset_Menu.gd：`MenuEdit` 新增两个开关——"启用/移除缩放手柄"（`RescaleToggle` ⇄ `ResizeButton`）与"启用/移除改尺寸手柄"（`SizeGripToggle` ⇄ `SizeGrip`）
- Config/UI/UIPreset_Keyboard.gd / UIPreset_Test.gd：底图说明同步（改用全局默认底图，不再各自写 `background` / `background_slice`）
- Script/Utils/Enums.gd：`OpenAt` 新增 `CENTER`（开在屏幕正中）
- Script/UI/UISystem.gd：新增 `screen_size()`——UI 坐标下的屏幕尺寸（`CENTER` 摆位与"自己按比例算尺寸"的预设共用，取视口可见矩形并保证非 0）
- Script/UI/Interact/UIInteract_OpenClose.gd：`open` 支持 `OpenAt.CENTER` 摆位；示例注释从 Status 换成 RoleData
- Script/UI/Interact/UIInteract_SetTop.gd：置顶改**两级**——窗口级（沿父链爬到最外层窗口）+ **自由层元素级**（爬到"父节点不是容器"的绝对定位层，把那一层的孩子提最前）：菜单与它开出的手柄同在一层，只提窗口提不动它们之间的先后（重开菜单会被手柄压住）
- Script/UI/Interact/UIInteract_Resize.gd：①下限改为 `max(全局最小尺寸, 内容最小尺寸)`——缩到最小就停住，不再让内容溢出/嵌套 UI 叠在一起；②位移 **÷ scale**（视觉尺寸 = size × scale，缩放后仍跟手）
- Script/UI/Interact/UIInteract_Rescale.gd：等比缩放只改 `scale`（手柄属于窗口、跟着一起缩；注释说明不把手柄钉回鼠标）
- Script/UI/Interact/UIInteract_Drag.gd：拖动的 `position` 在 CanvasLayer 坐标系（与鼠标同系），**不除 scale**（注释写明，避免再踩）
- Script/UI/UI/UIBase.gd：①`_fit_size`——收起时宽高都让给内容；**挂在容器里的元素不再自己写 `size`**（只报 `custom_minimum_size`，修与容器分配打架的排版振荡）②`_config_size` **删除 `size_ratio` 分支**（比例尺寸改由预设自己算，见 UIPreset_View._panel_size）③`_make_background` / `_apply_background`：没写 `background` 的面板统一套全局默认底图 ④`show_at` 全局坐标换算**除以父级 scale**（修缩放后手柄浮窗 Tip 漂移）
- Script/UI/UI/UI_Panel.gd：①`_apply_background` 覆写——所有面板（含嵌套的格子/段）都套默认底图 ②**嵌套面板竖向滚动条常驻**（`SCROLL_MODE_SHOW_ALWAYS`，斩断"滚动条出现/消失 → 可视区宽变 → 折行变 → 内容高变"的双稳态振荡，修看板开着就 signal 11 闪退）
- Script/UI/UI/UI_Label.gd：`fill_width`（顶满容器、自己那份宽仍算最小宽）与 `_keep_min_width`；`resized → _refit` 跟随折行重算高度
- Script/UI/UI/UI_View.gd（新增底座）：一览通用骨架——一条一段、默认收起、展开才建 `items`、实时订阅、只重铺那一段；六个一览共用
- Script/UI/UI/UI_Status.gd / UI_Attr.gd / UI_Interaction.gd / UI_Skill.gd / UI_Shortcut.gd / UI_Archetype.gd：改为 `UI_View` 钩子式一览（只回答"看谁/铺什么/订什么"），摆进看板六格；快捷一览改"一条一段 + 展开出输入框"
- Script/UI/Interact/UIInteract_Fold.gd：可折叠标题 / 段构造器调整（标题 `fill_width` 顶满、段标题限宽），配合收起宽度与看板格子
- Script/UI/UI/UI_Editor.gd：适配一览骨架的小改
- Script/UI/UI.md：同步 底图全局化 / 收起宽度 / 容器孩子不自写尺寸 / 嵌套面板滚动条常驻 / 删除 size_ratio / 置顶两级 / 开关式按钮与手柄 / 看板入口 等设计说明
- Script/Character/Status/Skill/Archetype/SystemShortcut 的 .md：四个一览的"在哪看、怎么开"条目改为看板入口
- Script/Character/Attribute/Attributes.gd、Interaction/InteractionPreset.gd：注释里的"想看它长什么样"指向改为看板
- Script/System/test.gd：演示改为开 RoleData 等新预设；TestShow 加 **`[img]` 富文本图片演示**（原始尺寸 + 16×16 + 64×64 三张，用全局底图，写外壳 `config["content"]` 后 `refresh_tree()`）
- Script/更新日志.md：清空旧条目（本轮重写）
