# 更新日志

## 0.26.7 角色身份交接

- 之前实现了用`unique_name`来定位角色，改为了`identity`
- 然而，身份是固定的，不同时间的同一身份对应的角色却不固定
  - 即这场比赛的对手和下场比赛的对手，都是对手`identity`，但不是一个角色
- 因此，更新了消息系统和角色系统，让角色系统在`identity`更新时，同步更新对应的接收器
  - 之前监听对手的，会把其消息ID转给角色系统保存，以同步更新`identity`和相关接收器
  - 消息节点里面添加了一个`identity_receivers`，和原本的`receivers`一样，只是它会在`identity`更新时同步迁移到新节点
- 此外，使用`identity`的方法，是参考之前的`type_name`里面加上`@identity`后缀，如果有后缀就直接转接到对应角色的节点上
- 然后增加了对`null`角色的处理，需要用`identity`消息时，留空占位即可，不管留不留空，都会转接到对应角色
- 最后让AI加了一个刷新LSP的脚本，减少我手动刷新的工作量，也避免AI因为缓存问题进行重复检查，但我还没试过，下个版本试

### 新增 · identity 绑定接收器与迁移（消息节点）
- 说明：把 `@identity` 定向的监听单独记为"身份接收器"，它和普通接收器**一样参与广播**；identity 换角色（或该 identity 首次出现）时，这些接收器会被迁到新角色对应的消息节点上——于是"identity 还没出现就先监听"和"identity 换绑到新角色"两种情况，监听都不会丢。

### 修改
- `Script/Character/Character.gd`：`unique_name` → `identity`；`_init` 参数顺序调整为 `(archetype_type, identity, name)`（identity 提到第 2 位），identity 非空时调 `CharSys.bind_identity`。
- `Script/Character/CharacterSystem.gd`：`unique` → `identities`、`bind_unique` → `bind_identity`、`get_by_unique` → `get_identity`；`spawn`/`create_char` 签名改为 `(race_name, identity, name)`；`bind_identity` 除写字典外还调 `MsgBus.rebind_identity`，把绑定到该 identity 的接收器迁到新角色对应的节点。
- `Script/Message/MessageNode.gd`：新增 `identity_receivers`——与 `receivers` 一样参与广播，唯一区别是 identity 变更时会被迁移；分两份存，避免迁移时误搬走恰好挂在该节点上的普通监听。
- `Script/Message/MessageBus.gd`：`listen` 新增 `identity_bound` 参数（true 时记入 `identity_receivers`）；`send` 依次广播 `receivers` 与 `identity_receivers`；新增 `_aliases`（旧节点 ID → 新节点 ID 的别名，供迁移后仍能退订）与 `_identity_bindings`（identity → [当前节点ID, receiver, 节点ID工厂]），以及 `bind_identity_receiver` / `rebind_identity` / `_move_identity_receiver` / `_resolve_alias`；`unlisten` 改为顺别名链找当前节点退订，并同步清掉 `_identity_bindings` 里该 receiver 的登记（否则注销后 identity 出现时又会被迁回来）。
- `Script/Message/MessageHub.gd`：`_resolve_target` / `_format_character` 中的 `unique_name` → `identity`；`_format_character` 支持 `char_` 为 `null`（`@identity` 尚未解析出角色时用它占位，以 type_name 里的 identity 造临时标签，随后由迁移修正）；`_listen_character` 对含 `@` 的监听以 `identity_bound=true` 挂载并调 `bind_identity_receiver` 登记；`send_pointer_move` / `listen_pointer_move` 去掉 `key` 的默认值与 `callback` 的 `Utils.identity` 默认值。
- `Script/Utils/Utils.gd`：删除恒等函数 `identity(x)`。
- `Script/Input/InputSystem.gd`：`Msg.send_pointer_move()` → `Msg.send_pointer_move(0)`（该函数已无默认参数）。
- `Script/System/SystemManager.gd`：`CharSys.create_char("SYS", "SYS", "SYS")` → `create_char("SYS", "SYS")`（第 2 个参数语义已由 name 变为 identity）。
- `Script/System/test.gd`：`CharSys.spawn("人类")` → `CharSys.spawn("人类", "player")`（给角色 A 绑定 identity `player`）。
- `Script/Character/Status/StatusPreset.gd`：注释里的 `状态名@unique_name` → `状态名@identity`。
- `Script/Character/SystemShortcut/SystemShortcutPreset.gd`：注释里的 `状态名@unique_name` → `状态名@identity`。

### 新增 · 工具脚本
- `tools/godot_lsp_restart.bat`（新）：单行内联 PowerShell 的 LSP 重启脚本，等价于 VSCode 命令 `godotTools.startLanguageServer`（VSCode 没有可从外部执行命令 ID 的 CLI，故改在进程层做等价操作）——找到命令行带 `--lsp-port` 的 headless Godot 进程，杀掉后用完全相同的参数（项目路径 + 同端口）重新拉起。只匹配 headless 进程，不影响已打开的 GUI 编辑器。
