## 0.26.10 菜单即UI

- 上个版本是菜单即菜单，然而我检查了里面的函数，发现非常多的冗余，菜单UI和其它UI没有任何区别了，菜单的失焦关闭添加到了常规UI的功能里，不再具有特殊性
- 因此将菜单统一为UI，然后修改了一些AI写的UI树错误，大致是挂载位置错误，且指令跟踪对象错误
- 有一说一，这个版本的AI很给劲，没有出现什么问题，一些我延后没提的问题也自行修复了，还用上了Godot探针，我也不知道那是啥，看起来是用命令启动Godot游戏？反正运行的很好，虽然积分耗的多了点，但现在打折，问题不大


### 修正 · 挂载点 = 锚点优先（`UiSys.open_ui`）

- 之前由 `host` 参数决定挂哪：菜单项里写 `open_ui $parent.parent MenuEdit $self`，宿主算出来是 MiniHUD，于是**子菜单挂在 MiniHUD 下、成了菜单A 的兄弟**，树长这样：

  ```
  MiniHUD
  ├─ Menu(菜单A)            ← Close / Edit 在这里
  └─ MenuEdit(菜单B)        ← 它是菜单A 的兄弟，不是后代 ✗
  ```

- 现在：`anchor`（触发它的那个元素）优先做挂载点。

  ```gdscript
  # 挂载点：锚点优先（子菜单挂到菜单项下 ⇒ 菜单链是一棵子树），其次宿主，都没有就挂 UI 根
  var mount: UIBase = anchor if anchor != null else host
  ```

- 于是链变成一棵**单链子树**：

  ```
  MiniHUD → Menu → Edit(菜单项) → MenuEdit → AddClose / EnableDrag / Advanced
  ```

### 说明 · 这就解决了"点子菜单却关掉父菜单"

- `UiSys.close_blur_ui` 判"指针在不在我这条链上"用的是 `_is_inside(ui, hover)`：hover 沿 `parent` 链向上找 ui（"失焦"= 指针不在我这条链上，点链外的任何地方才算）。
- 子菜单是菜单项的**后代**时，鼠标在子菜单项上 → 链里能走到菜单A ⇒ **不关**；之前是兄弟 ⇒ 走不到 ⇒ 被误关。
- 所以这件事由**结构**保证，不需要 `parent_menu` / `child_menus` 那套父子菜单登记（上一版已删，这次也没加回来）。

### 修正 · `挂载点=>预设名` 的登记名之前根本没生效（会重复建实例）

- `_build_open` 走的 `UIBase.add_child_element` 内部按 `挂载点/名字` 登记，而 `open_ui` 用 `挂载点=>预设名` 去查 ⇒ **永远查不到 ⇒ 每次开同一个菜单都会新建一份重复实例**，旧实例还留在 `uis` 里。
- 改法：登记名由开 UI 的路径**显式指定**——

  ```gdscript
  static func register_child(parent: UIBase, child: UIBase, reg_name: String = "") -> void
  func add_child_element(child_name, ui_class, child_config := {}, reg_name: String = "") -> UIBase
  ```

  `_build_open` 传 `_reg_name(mount, preset_name)`；普通子元素仍留空走 `父登记名/子名`。
- 登记表现在实测长这样（**UI 之间用 `=>`，UI 内部子元素用 `/`**）：

  ```
  MiniHUD | MiniHUD/Title | MiniHUD/Close | MiniHUD/Info
  MiniHUD=>Menu | MiniHUD=>Menu/Close | MiniHUD=>Menu/Edit
  MiniHUD=>Menu/Edit=>MenuEdit | MiniHUD=>Menu/Edit=>MenuEdit/AddClose | …/EnableDrag | …/Advanced
  ```

### 注意

- **链每深一层，到宿主就多一级 `$parent`**：`Menu` 的项 2 级、`MenuEdit` 的项 4 级，再深一层就是 6 级。级数写多/写少时 `resolve_cmd` 会 `push_warning` 并用可达的最高级替代——**写错不一定报错**，注意看输出。
- 菜单项里 `open_ui` 的挂载点与锚点**都传 `$self`**：锚点决定挂哪，所以子菜单才会挂到"触发它的那个菜单项"下。
- 旧 json 仍是老问题：`Archetype_System.json` / `UIPreset_Basic.json` / `UIPreset_Menu.json` 会覆盖代码里的 `values`；当前 `Sys.RESET = true`（每次启动重新写盘、不读旧 json），不需要手动清理。
