## 0.26.31 可变网格UI排布

- 实现用二维矩阵来定位UI位置，且面板缩放时，网格内格子会跟随变化

```python
static func _gcell(id: int, text_: String) -> Array:
    return [str(id), "UI_Label", {
        "grid": id,
        "content": "%d：%s" % [id, text_],
        "background": UIPreset_Keyboard.KEY_BG, "background_slice": UIPreset_Keyboard.KEY_BG_SLICE,
        "font_color": UIPreset_Keyboard.FONT_COLOR,
    }]
    
["MatrixTest", "UI_Panel", {
    "position": [560, 40],

        [1, 1, 1, 1, 1, 1],
```

### 更新内容

- `UI_Panel`：
  - config 新增 `matrix`（二维矩阵）与 `gap`（格间距，不写 = 4）：配了 `matrix` 的面板，内容盒换成
    普通 Control（不做任何布局），子元素的 position/size 由面板按矩阵算——
    **同一个编号出现几格 = 那个元素跨几格 / 跨几行**（跨格/跨行不用容器、不用嵌套）
  - 想进网格的子元素写 `grid: 编号` 声明自己占哪格；**没写的子元素不参与网格**（关闭按钮、竖排内容可混用）
  - 面板尺寸一变就重算（`_fit_size` 收尾 + 内容盒 `resized`）：**拖"改尺寸"手柄，格子按比例跟着缩放，
    排版不变**；四周留白就是面板的 `margin`；矩阵面板的 `size` 要定死
  - 新增静态 `grid_rect(矩阵, 宽高, 间距, 内边距, 编号) -> Rect2`（纯几何，配置层也能调）：
    L 形区域警告一次按外接矩形放；编号不存在 / 矩阵为空返回空 Rect2
- `UIPreset_Test`：新增 `MatrixTest` 演示窗（4×6 矩阵：1 号满宽、2/3 号半行、4 号跨两行两列且是面板、
  5–8 号标签——不同位置用不同元素）+ `_gcell` 演示格子助手
- `test.gd`：`MatrixTest` 并进"带手柄窗口"的开启循环（Keyboard / SizeTest / MatrixTest 同一套）
- 实测：500×320 ⇒ 1号 484×73 满宽、2/3号各240×73 半行、4号 158.7×150 跨两行两列；
  拖手柄 (+120,+80) ⇒ 620×400：1号 604×93、4号 198.7×190、8号 (413.3,299)——排版不变按比例缩放 ✅
