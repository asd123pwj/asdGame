# 更新日志
## 0.26.37 画点UI

- 试了试QWen Image 2.1，画像素图还是不行
- 然后基于生成的图像重画了一下，加了几个UI，突然开悟了，感觉画的比以前好



- 新画的竹子素材接进来了：角色看板窗口的底（空框那版）、关闭按钮、等比缩放 / 改尺寸两个手柄、滚动条（轨道 + 抓手）
- 三个"外置按钮"（关闭 / 等比缩放 / 改尺寸）改成排在窗口**右侧外面的一列**里：列左沿 = 窗口右边缘、从上往下排
  - 按钮不再占窗口内容的地方，窗口拖多小都摆得下，也不再压住窗口里的字
  - 顺手修了个老问题：右下角那一排在窗口**下沿外面**（挂出的量正好 = 图标高；图标从 32 换成 64 后才显眼）
- 滚动条：条宽 8 → 12（**图多宽、条就多宽，横向 1:1 不缩放**）；抓手最矮从 4px 提到 8px；中段**平铺**（竹节原样重复，拉伸会按长度等比放大）
- 看板每格的字宽上限一路量着收到 38（竹框的四角 16 + 滚动条 12 都要从格宽里扣），保证不溢出右邻格
- 可选框打勾的图也放进项目了（同族 64×64），但项目里还没有可选框元素，暂时用不到


修改简述：

- Config/SystemConfig.gd：①新增"滚动条皮肤"配置段（`ui_scroll_track` / `ui_scroll_grabber` / `ui_scroll_side`（条宽 = 它 × 2）/ 轨道与抓手的端帽 / `ui_scroll_stretch`（中段平铺或拉伸）/ 悬停与按下的调色）——**换图、改条宽、改端帽都只动这几行**；②`resize_min_size` 注释重写：手柄外置后它不再由图标尺寸推（值仍是 96×64）
- Config/UI/UIPreset_Basic.gd：①图标常量换成竹子那套（`CLOSE_ICON` / `RESCALE_ICON` / `RESIZE_ICON` + `ICON_SIZE = 64`，一律**按原图 1:1**、不缩放）；②`handle_cfg` 增加"图标"参数（两个手柄各用各的图）；③关闭按钮与两个手柄的 `open_at` 全改成 `ANCHOR_RIGHT_OUT`（挂进右侧外那一列）
- Config/UI/UIPreset_View.gd：①看板窗口的底图显式换成竹框 `UI_Bamboo_Empty.png`（`background_slice: 16` + `background_stretch: "tile"`）——不写 `background` 就会用全局默认那张圆角方块；②`CELL_CHARS` 40 → 38（扣掉竹框四角与滚动条），推导注释同步
- Script/Utils/Enums.gd：`OpenAt` 追加 `ANCHOR_RIGHT_OUT`（外置按钮列；**新值一律加在末尾**——已存盘的 json 里记的是枚举整数，插中间会让旧值串位）
- Script/UI/UI/UI_Panel.gd：①`_corner_box` 增加"右侧外面一列"容器（VBox：列左沿 = 宿主右边缘、上沿 = 宿主上边缘，往右往下长到面板外），并修掉右下角那排**整排挂到窗口外**的老问题（`grow_vertical` 没写 ⇒ 默认向下长）；②新增 `_apply_scroll_skin` / `_scroll_style`：给**引擎画的**滚动条（`ScrollContainer` 的内部 `VScrollBar`）打主题覆盖（轨道 `scroll` / `scroll_focus`、抓手 `grabber` / `grabber_highlight` / `grabber_pressed`）——**条宽 = 左右切边之和**（图多宽条就多宽、横向永远 1:1），悬停 / 按下复用同一张图调色，不另画
- Script/UI/UI/UIBase.gd：①`_make_background` 支持 `background_stretch`（`"tile"` 平铺）——**图案有细节的边框必须平铺**：拉伸会把图里 2px 的竹节按面板宽等比放大成一条很宽的暗带；②`_anchor_free_child` 注释补上新策略的归属（外置列不走它，由面板的角落容器整列管）
- Script/UI/Interact/UIInteract_OpenClose.gd：`_place` 增加 `ANCHOR_RIGHT_OUT` 分支——**不摆位**（位置由面板的角落容器整列维护，写了也会被容器覆盖），只负责显示
- Script/UI/UI.md：同步三条说明——底图"平铺 / 拉伸"（`background_stretch`）、外置按钮列（`ANCHOR_RIGHT_OUT`，含"画在窗口外照样能点"）、滚动条皮肤（不走 `background`、条宽怎么定、换条宽要回头改 `CELL_CHARS`）
- Script/System/test.gd：清掉临时探针留下的空行
