# 更新日志

## 0.26.4 内联配置

- 配置越写越多，而许多配置只给系统状态用，但分离在不同类型的配置文件下，非常难改
    - 时不时就报个不存在的错误
- 因此将Archetype改为内联配置，原有读取策略不变，但可以以内联形式创建，不需要在特定类型的配置文件里创建
- 一言以蔽之
```json
    # 原始版本，名称指向对应配置
    {
        "name": "通用活体",
        "buffs": ["人被杀就会死"],
        "statuses": ["Dead", "Live", "Injured", "Detect=>Practice", "Health<=Base/2"],
        "interactions": ["Practice", "SayInjured", "TryHealSelf"],
        "packages": ["CanBeHealed", "Nourish", "重力与阻力"]
    },


    # 内联版本，直接写配置
    {
        "name": "SYS",
        "packages": ["输入监控", "指针监控", "时间周期", "其它"],
    },
    {
        "name": "其它",
        "statuses": [
            {"name": "AlwaysSatisfied"},
        ],
    },
    {
        "name": "输入监控",
        "statuses": [
            {"name": "Right", "match_any": true, "keys": [[KEY_RIGHT, Enums.KeyStatus.DOWN], [KEY_D, Enums.KeyStatus.DOWN]],}, 
            {"name": "Up", "match_any": true, "keys": [[KEY_UP, Enums.KeyStatus.DOWN], [KEY_W, Enums.KeyStatus.DOWN]],}, 
            {"name": "Left", "match_any": true, "keys": [[KEY_LEFT, Enums.KeyStatus.DOWN], [KEY_A, Enums.KeyStatus.DOWN]],}, 
            {"name": "Down", "match_any": true, "keys": [[KEY_DOWN, Enums.KeyStatus.DOWN], [KEY_S, Enums.KeyStatus.DOWN]],},
        ],
    },
```

### 新增 · Archetype 内联配置
- 说明：archetype 各模块数组的元素，现在既可是"预设名"字符串（引用别处已定义的配置），也可直接写"内联配置"（字典/列表）；内联则按字段对应的类现场创建并注册。由此"只在一处出现"的模块（如系统专用状态/快捷）可内联进 archetype，无需另建配置文件。
