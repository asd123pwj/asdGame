# 更新日志
## 0.26.36 清晰放大

- DeepSeek大人还是厉害，GLM 5.3 Flash耗的积分太多了，感觉有十倍的差
- 杀戮尖塔2是用Godot做的，我还没买，听说一个问题是放大会模糊。
  - Unity里面有一个选项可以改，Godot里面倒是没找到
- 于是我用最近邻采样来放大图片，文本用线性采样
  - 因为都是像素素材，本来就不是平滑的，所以最近邻非常适合像素
- 现在放大很清楚。不过不知道是否能在所有素材都有效


修改简述：

- project.godot（**注意：本文件被 .gitignore 忽略、不入库**）：新增 `rendering/textures/canvas_textures/default_texture_filter=0`（0 = 最近邻）——**全项目画布采样的唯一开关**，UI 底图 / 图标 / 关闭按钮、角色图（`Sprite2D`）、地图瓦片、特效……所有图跟着走；**引入新图不用改任何东西**（Godot 4 的贴图导入里没有"过滤"项，逐张改也做不到，本来就只能走这个全局值）。**注意**：因为不入库，换机器 / 重新克隆后要手动再加这一行（编辑器里：Project Settings → Rendering → Textures → Canvas Textures → Default Texture Filter = Nearest）
- Script/UI/UI/UI_Label.gd：`_create_control` 给 RichTextLabel 显式设 `CanvasItem.TEXTURE_FILTER_LINEAR`——**文字必须线性**（字体是 MSDF 距离场，靠插值求字边，最近邻会让字发毛、坑洼；实测全局改最近邻后字明显变糙），并注释写明"谁新建带文字的控件就照这里补一行"
- Script/UI/UI/UI_Input.gd：同上——LineEdit 与 TextEdit 两处都设 `TEXTURE_FILTER_LINEAR`
- Script/UI/UI/UI_Panel.gd：`_create_control` 删掉根 / 底图 / 内容盒三处 `texture_filter`（原来为了 MSDF 分"图像最近邻、文字线性"两层），改用注释指向全局开关
- Script/UI/UI/UI_Image.gd：删掉 `texture_filter`（不再自己指定，跟全局最近邻走）
- Config/SystemConfig.gd：字体那段注释补一句——**MSDF 必须配线性采样**、只设在 `UI_Label` / `UI_Input` 两处，全项目其余（含角色图 / 瓦片）走 project.godot 的最近邻全局默认
- Script/UI/UI.md：采样说明改写为"**图 = 全局最近邻（一处生效、加图不用改）/ 字 = 文字控件线性（两处）**"，`UI_Image` 行同步（不再自己设采样）
- Script/更新日志.md：写入本轮条目（上一版 0.26.35 的条目按惯例清掉，需要时在 git 里查）
