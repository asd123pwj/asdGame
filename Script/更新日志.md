# 更新日志
## 0.26.38 更好的打开位置

- 修正了在使用窗口A，但鼠标移动到窗口B上，弹出浮窗时，会置顶窗口B的问题
- 修正了浮窗被剪裁的问题
- 添加了打开位置序列，鼠标最近邻策略，让右键菜单，浮窗更好的显示
  - 打开位置找到折叠最小的位置
  - 浮窗在鼠标最近的位置打开
    - 这个是指浮窗不在鼠标位置打开的情况，有时要看一整段文字，浮窗不应该挡在文字上



- 把"同一个东西在好几处各写一遍"的代码收成一处（UI 里尺寸计算、配置读法、订阅回调、哈希与调试图存盘、那一族文字颜色）
- 清掉已经用不上的：**118 个"只剩 `.uid`、源码早就没了"的残留**、3 个"图已删、只剩导入记录"的 `.import`、两张被换掉的旧按钮图，以及几个没人调用的工具函数与历史遗留常量
- 顺手**修了一个真 bug**：状态里挂 `"Month"` 的时间监听被复制粘贴串成了 `"Xun"`（而"旬"这一粒度早已移除、`send_advance_xun` 从不发）⇒ 挂 `Month` 的状态一直收不到消息
- **界面外观与数值零变化**：这轮只改"代码怎么写"——不改配置值、不改配色值（原值搬个名字）、不改尺寸算法


修改简述：

**一、合并重复**

- Script/UI/UI/UIBase.gd：
  - 新增 `_as_vector2()` —— 读 `[宽, 高]` 这种"二元数组"配置的助手（**别处再写"是不是数组、够不够两项、转 float"就是漏改**）；
  - 新增 `_repeat_fit()` —— "连几帧各重算一次尺寸"（等排版稳定，有界）；
  - 新增 **UI 文字配色常量** `TEXT_DIM_COLOR` / `TEXT_NONE_COLOR` / `TEXT_YES_COLOR` / `TEXT_NO_COLOR` / `TEXT_ALERT_COLOR`：原来 UI_View 里那个 `COUNT_COLOR` 只覆盖了"总计那行"，其余同色字面值散在 7 个文件里，现在整族收到基类（各 UI 元素都继承它，直接用常量名）
- Script/UI/UI/UI_Panel.gd：`_margin` / `_scroll_cap` 改用 `_as_vector2`；新增 `_gap()` —— 两处网格排布的 `gap` 默认值（4）只此一处
- Script/UI/UI/UI_Label.gd / UI_Input.gd：`_refit` / `_reheight` 改用 `_repeat_fit`（UI_Input 那条"正在编辑就别算"留在自己这层）
- Script/UI/UI/UI_Status.gd：`_subscribe` 的六条订阅**共用一个回调**（原来六份一模一样的 lambda，各订一条）
- Script/Utils/Utils.gd：新增 `hash_bitmap()`（位图 → MD5 缓存键）与 `save_debug_png()`（调试图存盘）—— 原来**两个 Tilemap 预设各写一份一模一样的**
- Script/Tilemap/TileSpritePreset.gd / TileSetPreset.gd：删掉各自的 `_hash_bitmap` / `_hash_mask` / `_save_debug_png`，改用 Utils；`texture_origin` 那处硬编码 `Vector2i(-8, 8)` 改用**早就定义着、却一直没人用**的 `SysCfg.P3D_TILE_ORIGIN`
- Script/UI/UI/ 其余一览（UI_View / UI_Attr / UI_Status / UI_Skill / UI_Interaction / UI_Shortcut / UI_Archetype / UI_Editor）：字面颜色值全部改用上面的常量

**二、清掉用不上的**

- **118 个孤立 `.uid`**（`Script/UI/UIBase.gd.uid`、`Script/Utils/PresetRegister copy.gd.uid`、`tools/ui_visibility_probe.gd.uid`、`Script/Command/*.cs.uid` 等）：只剩导入元文件、对应源码早已删除 / 改名 / 搬到子目录。删除是安全的（Godot 会为**存在的**脚本重新生成），这类文件本就被 `.gitignore` 忽略
- **3 个孤立 `.import`**：`UI_Bamboo_Panel` / `UI_Bamboo_panpel` / `UI_Bamboo_panpel_64` —— png 早已不在项目里，只剩导入记录
- Material/Texture/UI/：`CloseButtom_16.png` / `ResizeButtom_16.png`（含其 `.import`）—— 换竹子那套后代码里 0 引用
- Script/Utils/Utils.gd：删 `get_or_set_dict`（无调用者）
- Script/Time/TimeSystem.gd：删 4 个历史遗留常量 `msgID_advance*`（原注释自述"当前无人用"）
- Script/Time/TimeFormat.gd：删**永远为空**的 `xun` 字段与注释掉的 `_旬` 表（"旬"已从时间粒度里移除）
- Config/QuickName.gd：删 `UI_event_pointer1_close_parent`（同族 `_close_host` 在用，这条 0 引用）
- Script/Message/MessageHub.gd：删 `send_cmd0`（`send_cmd00` 仍在用）
- Script/Tilemap/TileSpritePreset.gd：删 `if false:` 里那次调试图存盘（死块）

**三、修 bug**

- Script/Character/Status/StatusPreset.gd：`"Month"` 时间监听误写成 `listen_advance_xun`（复制粘贴串到了下一支）⇒ 改回 `listen_advance_month`。原来挂 `"Month"` 的状态**永远收不到消息**（旬已移除、`send_advance_xun` 从不发）。`"Xun"` 那一支保持原样并加注：旬已移除，挂它当前不会触发

**四、摆位策略收口：提示浮窗改用一个 `open_at` 值**

- Script/Utils/Enums.gd：`OpenAt` 追加 `ANCHOR_NEAREST` —— **贴锚点顶点 + 挑离指针最近的那个角**（就是原来的 "`ANCHOR_TOP_RIGHT` + `nearest: true`" 两处写法合成一处）。照例**追加在末尾**（枚举整数已进存档，插中间会串位）
- Config/UI/UIPreset_Basic.gd：`tip_cfg` 改成只写 `"open_at": Enums.OpenAt.ANCHOR_NEAREST`，不再配 `"nearest": true`
- Script/UI/Interact/UIInteract_OpenClose.gd：①`_place` 认识新策略（这个策略名本身就等于"最近优先"；别的策略仍可用 `nearest: true` 补一条）；②`_anchor_positions` 的"顶点版 / 内部版"判据改成**显式白名单**——原来写的是"**不等于** `ANCHOR_TOP_RIGHT` **就算内部版**"，新加一个顶点版策略会被**静默**当成内部版（加 `ANCHOR_NEAREST` 时实测踩到：浮窗跑到锚点里侧去了，探针逮出来才修）

**五、文档**

- Script/Utils/Utils.md：Utils 的职责与函数清单同步（去掉 `get_or_set_dict`，补 `hash_bitmap` / `save_debug_png`）
- Script/Time/Time.md：去掉已删除的 `msgID_advance*` 那条
- Script/UI/UI.md：`open_at` 清单补 `ANCHOR_NEAREST`；"离指针最近"的两种写法（`ANCHOR_NEAREST` / `nearest: true`）同步
