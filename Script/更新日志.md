## 0.26.27 角色原型查看UI

- 无甚好讲，这次连实时都没有，就是初始化时的包装盒名称

### 更新内容

- **新增：角色原型一览**（`Config/UI/UIPreset_Archetype.gd` + `Script/UI/UI/UI_Archetype.gd`）
  - 打开：`UIInteract.open(preset_name="Archetype")`，默认看 `char_A`（换人写 `content_cmd="@Char/兔子"`，再点 `[刷新]`）
  - 取法：`Character.archetype_type`（初始化入参，见 `Character._init_from_archetype`）→ `Archetype.get_(...)`，铺的时候读一次
  - **一个字段一段**（`buffs` / `statuses` / `interactions` / `bodies` / `skills` / `collisions` / `inventories` /
    `shortcuts` / `packages`——`behaviors` 在 `Archetype` 里已被注释掉，所以不列），段标题是 `字段（N 项）`，
    段里一行一个预设名。**非空默认摊开**（静态配方，收着看不出所以然），空字段收着省地方
  - 抬头那行写明两件容易误会的事：这份清单是**合并 `packages` 之后**的（`Archetype.get_` 第一次取时会把各包的字段
    并进来：buffs 不去重、其余去重），以及"只在初始化时装配一次"
- **"不实时的一览"怎么写：不覆写 `_listen`**（`UI_View` 基类是空实现 ⇒ 一条消息都不订，`_subs` 一直是空的）。
  这是第一个这样的元素，`UI_View` 的类注释里也把这条规矩写明了（不需要实时就别覆写 `_listen`）
- **顺带**：`ui_test` 多开一个原型一览；`Archetype.md`（加"想看它长什么样"那段 + 提醒看到的是合并后的清单）、
  `UI.md`（一览清单五个 → 六个，并标出原型那个是唯一不实时的）
- 验证：探针实测——**订阅数 = 0**（真不实时）；人类原型铺出 9 段：
  `buffs 5 / statuses 10 / interactions 9 / bodies 1 / skills 6 / collisions 1 / inventories 0 / shortcuts 0 / packages 8`，
  非空段摊开、空段收起、行数与项数一一对上；`--headless --editor` 全项目解析 clean、`--headless` 跑起来无脚本错误
