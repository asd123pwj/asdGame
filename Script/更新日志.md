# 更新日志
## 0.26.39 延时指令

- 举例，鼠标停止0.5秒后才打开浮窗
- 给时间系统增加了延时函数，接受时间，指令，取消状态，监听角色
- 浮窗的延迟，就是把打开指令外套一层延时指令，

```python
static func tip_open_cmd(text_: String, preset: String = TIP_PRESET) -> String:
    var open_cmd: String = 'UIInteract.open(@self, "%s", @self, content="%s")' % [preset, text_]
    return "TimeSys.after(%s, '%s', cancel_on=\"%s\")" % [TOOLTIP_DELAY, open_cmd, QName.pointer_move]
```








- 新增"**过几秒再执行一条指令**"的机制，放在时间系统里：`TimeSys.after(秒, 指令串, cancel_on=…, 角色=…)`
  - **同一条指令再次登记 = 只把等待时间重置**（判"同一条" = **同一串指令**）⇒ 反复登记就是"停住才执行"；
  - `cancel_on` = **取消条件 = 角色状态名**（看哪个角色由可选参数 `char_` 决定，**不写 = SYS 角色**）：
    订一条**一次性**的"状态满足"监听，那条状态一满足就作废；
- 提示浮窗因此变成"**指针停住（TOOLTIP_DELAY）才弹**"：每次移动重新计时、**一动就作废**——
  **开窗指令本身一个字没改**，只是被包了一层延时（以后别的地方想延时也这么包）
- 给"指针移动"补了**状态身份**：`Pointer Move` 现在既是派发给 hover 元素的 UI 事件，也是 SYS 角色上的
  **瞬时状态**（这一帧动过就亮一下）⇒ 状态层终于能"看见鼠标动了"（取消条件就写它）
- **说明浮窗统一到一个入口**：原来"打开说明浮窗"是各拼各的（关闭按钮 / 两个手柄走 `tip_events`，
  而 MetaTest 的两扇浮窗、折叠箭头的说明各拼一条裸 `UIInteract.open`）⇒ 现在只有 `UIPreset_Basic.tip_open_cmd`
  一处会拼它（`tip_events` 给"整块元素"、`tip_hover_bind` 给富文本链接），延时与"一动就作废"自然处处一致
- 指令语言补了**单引号字符串**：这样"把一整条指令串当参数传"才写得出来（里面还要写双引号）
- 顺手把指令解析里三处"引号判定"的口径统一了（也修掉"`"it's"` 里的单引号被当成字符串结束"的隐患）


修改简述：

- Script/Time/TimeSystem.gd：新增"延时指令"一节
  - `after(seconds, cmd, cancel_on = "", char_ = null)`：过 N 秒执行一条指令（真实时间，与 tick 同一把尺、
    不看时辰快慢）。**判"同一条"只看 `cmd`**（同一串指令就是同一条，不记谁登记的）——同一条再次登记
    只重置等待时间，换成这次给的秒数（比原来的长、短都换）；
  - 登记时顺手记下"当时正在派发事件的元素"（**内部字段 `from`，不是给配置写的参数**）：**执行时靠它解析
    `@self` / `@host`**——延时执行时早就没有"当前事件"了（`CommandParser.event_ui` 那条提醒：不在派发链上的
    指令别写 `@self`）。以后真要"按谁登记的分开算 / 分开取消"，再加一个 `who` 参数即可；
  - `cancel_on` = **角色状态名** + `char_` = **看哪个角色的状态**（**不写 = SYS 角色** `Sys.sys_status`，
    系统状态都挂在它身上；要看某个具体角色就传进来）：`_arm_cancel` 订一条
    `Msg.listen_status_satisfied(char_, ..., once=true)`，命中即 `_on_cancel_hit` 摘掉这条延时；
    **角色没取到只警告一句、这条照排**（不设取消条件，不静默失效）。
    **凭据（cancel_id / cancel_cb）存在条目里**：没命中却先到点 / 先被取消的场合，`_unlisten` 会主动退订
    ——不然每悬停一次就留一条监听；
  - `cancel(cmd)`：按指令串取消那一条；`cancel_all()`：全清（都走 `_drop`，顺带退订）；
  - `_tick_delays(delta)`：`_process` 里每帧倒计时，到点**先摘掉再执行**（执行前把 元素/事件名 摆回登记时的值，
    执行完还原）；登记它的元素已经被删掉的，顺手作废；
  - `_process` 里加一行 `_tick_delays(delta)`（在 `send_tick` 之前）。
- Config/Character/Archetype/Archetype_System.gd：给 SYS 角色加一条**瞬时状态**
  `{"name": QName.pointer_move, "auto_reset": true, "with_detect_transient": true}` ——
  "指针这一帧动过"。**同一个名字两种身份**：事件那份给 UI 元素，状态这份给状态层（延时指令的取消条件）。
- Script/Input/PointerDetect.gd：`_process` 里指针动过时，**先**发一条瞬时状态
  （`Msg.send_status_detected_transient(Sys.sys_status, QName.pointer_move)`）、**再**派发 `Pointer Move` 事件
  ——顺序要紧：先"作废旧的延时"，再由事件重新登记一条，效果就是"同一条指令的重置"。
- Config/UI/UIPreset_Basic.gd：
  - 新增 `TOOLTIP_DELAY`（指针停住多久才弹；改等待时长只动这一行）与 `TIP_PRESET`（默认那扇 "Tip" 的预设名）；
  - **新增 `tip_open_cmd(内容, 预设名)`**：**全项目唯一**拼"打开说明浮窗"那条指令的地方
    （包一层延时 + `cancel_on=QName.pointer_move`）。两条路都从它出发：
    `tip_hover_bind(内容, 预设名)` = 富文本链接用的**那一对**（`[事件名, 指令串]`，交给 `as_meta`）；
    `tip_events(内容)` = **整块元素**用的两条事件（悬停弹 ＋ 移开收窗）。
- Config/UI/UIPreset_MetaTest.gd：`TIP_ONE` / `TIP_TWO` 改成 `UIPreset_Basic.tip_hover_bind(...)`
  （第二扇传 "Tip2"）——**不再自己拼裸 open 指令**，于是这两扇浮窗也自动"停住才弹、一动就作废"。
- Script/UI/Interact/UIInteract_Fold.gd：标题箭头的说明同理（`_sym_meta` 改用 `UIPreset_Basic.tip_hover_bind`）。
- Script/UI/UI/UIBase.gd：撤掉上一版在 `on_event` 里结清取消条件的钩子（取消条件改成状态监听，不再需要）。
- Config/QuickName.gd：`pointer_move` 的注释写明"一个名字两种身份"（UI 事件 / SYS 瞬时状态）。
- Script/Command/CommandParser.gd：**字符串字面量开始认单引号**（`'…'`，与双引号一样成对即可）。
  三个扫描器（顶层冒号 / 顶层 `=` / 参数拆分）统一成"**记住是哪种引号打开的**"——另一种引号在它里面
  只是普通字符。于是"把一整条指令串当参数传"能直接写：`after(0.5, 'UIInteract.open(@self, "Tip", …)')`。
  引号内**不认转义**：要写引号就换另一种。
- Script/Command/CommandSystem.gd：头注释补"单引号字符串"那条（含一条现成例子）。
- Script/UI/Interact/UIInteract_Meta.gd：文件头的 meta 例子改成"用 `UIPreset_Basic.tip_hover_bind` 拼"，
  不再示范自己拼 `open(@self, "Tip"…)`。
- Script/Time/Time.md：新增"延时指令"一节（取消条件 = 角色状态名 + 一次性监听）。
  Script/UI/UI.md：`ANCHOR_NEAREST` 那条补"悬停还停住才弹"，并指向 `tip_open_cmd` 这个唯一入口。


验证（headless 探针，直接发状态 + 派发事件模拟悬停；验完已清理）：

- 停 0.3 秒：**没弹**（只是登记，不当场开）
- 中途再"动一下"、过 0.6 秒：**仍没弹**（重入重置生效）
- 距第二次移动 1.2 秒：**弹了**（延时执行时 `@self` 也解析对了）
- 登记后**只发"移动"状态**（= 指针又动了、但没落到这个元素上）、过 1.2 秒：**仍没弹**（取消条件生效）
- 可选角色（探针，`cancel_on` 都用一个"只有 SYS 才有、且每帧满足"的状态 Tick）：
  指定 `char_` 是别的角色时**这条还在**（那个角色身上没有 Tick）；**不传角色（= SYS）时当场作废**
- 统一入口核对（探针看生成出来的指令）：关闭按钮 / 两个手柄 / MetaTest 两扇浮窗 / 折叠箭头，
  **五处都含 `TimeSys.after(` 与 `cancel_on=`，没有一处还是裸 `UIInteract.open`**
- 全量解析 clean、运行 no crash、lint 无新增问题
