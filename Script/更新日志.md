## 0.26.19 UI Host

- 随着层级增多，如果依然依靠`.parent`的堆叠来爬到待管理对象，可能会产生遗漏。
- 因此，实现`host`，在打开UI时可以指定`host`，
- 因此，理论上所有的菜单打开都可以归纳为`[QName.mouseRight, 'UIInteract.open(self, "Menu", self, close_on_blur=true, host=self)']`
  - 不过我没测试

### 改动 · `config["host"]` 存**实例 ID**（Script/UI/UI/UIBase.gd）

- 存 ID 而不是实例：config 是数据（会被深拷贝、可能写盘成 json），实例存不进去；ID 就是个整数，json 能存（64 位 ID 超出 JSON 的 2^53 精度 ⇒ 数字字符串也认）。
- 两种设置方式：开的时候给 `UIInteract.open(self, "Menu", self, close_on_blur=true, host=self)`；运行中改 `Utils.write("<某个 UI 的路径>.config.host", self.ID)`——写成谁就以谁为界（它下面整棵子树都跟着走，更近的声明还能再覆盖，所以可以给不同子菜单挂不同的管理对象）。
- **是"管理对象"不是"挂载点"**：挂在哪、摆在哪仍由 `open` 的 target / anchor + `open_at` 决定。
- 值用不了（那个 UI 已经不在了 / 手写了个名字）⇒ 当"没声明"处理并**提醒一次**（按值去重，不刷屏）：一个笔误不该让整条指令失效，但也不该静默地管错对象。
- 文档同步：`Script/UI/UI.md`（菜单项里管理宿主一律写 `host`；管理对象不一定是顶层；`MenuBind` 写的是窗口的 config）、`Script/Utils/Utils.gd` 的路径示例、`UI_Input` / `UIInteract_OpenClose` 的注释。

### 顺手 · LSP 重启脚本（tools/）

- `tools/godot_lsp_restart.ps1`：逻辑独立成 ps1（`.bat` 只当入口）——有 LSP 进程就重启，一个都没有就按 `.vscode/settings.json` 的端口自己拉一个 headless LSP，并轮询到端口真的在监听。
- 验证：`--headless --editor` 全项目解析 clean；这一版动过的文件 lint 干净。

## 0.26.18 UI交互：折叠同级UI

- 这次AI很棒，没有边做边拉，调整几次就非常合我心意
- 折叠同级UI，指的是当UI特别多的时候，直接把一组的UI折叠掉
  - 原理看起来比较简单，就是`control.visible=false`
- 下面是做可折叠标题的模板，点击这个标题UI，就能折叠所有同级UI
  - 然后我看到了AI做了个`section`，让我想到之后可能会有不少这种改变层级的容器，
    - 这些容器各有不同功能，但自然他们都会影响到子UI的`.parent`查询，因为层级变多了
    - 所以应该可以加个`manage to`这种的标签，直接指向被管理对象，就能避免添加UI后频繁修改`.parent`层级的问题了
    - 这个标签应该是递归型的，如果有就继续递归，这样管理菜单统统递归上去就行。

```python
static func make_fold_title(title: String) -> Array:
    return ["Title", "UI_Label", {
        "content": "▾ %s" % title,
        "content_2": "▸ %s" % title,
        "collapse_keep": true,
        "events": [[QName.mouseLeft,
            'UIInteract.toggle_fold(self.parent)'
            + '\vUtils.swap("self.config.content", "self.config.content_2")'
            + '\vself.refresh("content")']],
    }]
    
var values: Array[Array] = [
    ["FoldDemo", "UI_Panel", {
        "position": [700, 30],
        "size": [270, 0],                            # 宽固定、高随内容 ⇒ 收起后自己变短
        "children": [
            make_fold_title("折叠演示"),              # 整块的标题（点它整块收起 / 展开）
            _section("SecA", "一段很长的配置", 8),
            _section("SecB", "又一段很长的配置", 8),
            _section("SecC", "第三段很长的配置", 8),
        ],
    }],
]
```

### 新增 · 收起 / 展开 = 交互指令 `UIInteract.fold`（Script/UI/Interact/UIInteract_Fold.gd）

- 解决的问题：一块 UI 的配置太长（子 UI 的"管理菜单"那种）会顶出屏幕下边。解法是**收起（隐藏），不是关闭**。
- 三个指令：`UIInteract.fold(target, collapsed=true)` / `UIInteract.unfold(target)` / `UIInteract.toggle_fold(target)`。
- 两个配置键（都在元素自己的 config 里，一份数据一处真相）：
  - 父元素上 `collapsed`：收起态（默认 false = 展开）；
  - **子元素自己**标 `collapse_keep = true`：表示"收起时留着我"（默认不标 = 跟着收起）⇒ "谁留下"写在自己身上，**父元素不用维护名字清单**，子元素改名 / 加删都不用回头改父级配置。
- 收起 = 其余子元素 `hide()`（**不销毁实例**，展开回来一切照旧）；不可见的子元素不参与容器布局 ⇒ 容器按内容收缩 ⇒ `size` 里为 0 的那一维（"宽固定、高随内容"）自己变短，收起后不再占屏幕。对比 `close`：那是把整个 UI 隐藏，所以不能用来"只收起一段"。
- 可以套娃：外层收起时里面整片不可见；展开外层后，每段仍保持它自己收起 / 展开的状态（状态各自记在各自的 config 里）。
- **实现只在交互里，`UIBase` 里没有折叠代码**：这事就是"把子元素的 visible 设一下"，不值得让基类为它多记状态、多几个方法。
- 从外面也能调（按键快捷 / 别的 UI / 菜单项）：`UIInteract.fold(UiSys.get_ui("FoldDemo"))`；想"开出来就是收起的"就在 `open` 那一句后面接一条 `fold`。
- 注意：收起期间**运行时新加的子元素**不会自动跟着藏（加完再调一次 `fold`）。

### 新增 · 一行"可折叠标题"（Config/UI/UIPreset_Fold.gd）

- `UIPreset_Fold.make_fold_title("标题")` 返回一条普通 `UI_Label` 配置——**它自己既是标题也是收回按键**：
  - 显示 `▾ 标题` / `▸ 标题`（两套 `content` 对调，见 UI.md 的"开关式按钮"）；
  - 点它 → `UIInteract.toggle_fold(self.parent)`，收起 / 展开它**所在的那个分组**；
  - 自带 `collapse_keep: true`（否则收起来就再也没有东西能点开它）。
- 于是"给一段内容加收 / 展"就是**加这一行**：别处直接 `children.append(UIPreset_Fold.make_fold_title("一段很长的配置"))`；想换样子（标题带底、或者另放一个 `[+]` / `[-]` 按钮）照抄这段改 `content` / `events` 即可。
- 演示 `FoldDemo`（`Test.ui_test` 里默认开出来）：整块一个标题 + 三段各自一个标题，套娃收起。

### 改动 · `UI_Panel` 套在容器里时高度恒为 0（Script/UI/UI/UIBase.gd）

- 症状：嵌套面板（比如"可收回的分组"）在容器里高度一直停在标题那一点——它的**根控件是普通 `Control`，不汇总子元素的最小尺寸**，父容器看不到它需要多大。
- 改法：`_fit_size()` 把补足后的尺寸**发布成控件的最小尺寸**（`custom_minimum_size`）；相应地"配置想要多大"改读 `config["size"]`（新增 `_config_size()`），不再读 `custom_minimum_size`（那个值现在表示"内容实际多大"）。
- 对已有的扁平布局是等价的（它们本来就靠自己的最小尺寸报高）。

### 验证

- 探针实测（跑完即删，连跑两次一致）：整块 **800 ↔ 35**、每段 **251 ↔ 35**（收起后只剩那一行标题）；点标题走完整指令链，收起 / 展开状态与箭头文字（`▾` / `▸`）都对。
- `collapse_keep` 在**运行时新加**的子元素上同样生效：标了的留下、没标的跟着藏。
