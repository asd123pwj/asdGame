# 更新日志

## 0.26.33 角色属性总览

- 把之前实现的六个属性窗口挪到一起了，虽说是属性总览，不过还有一些没做完的角色配置没加进来
- 中间卡死过一次，似乎是因为大小自适应卡死的，UI的大小，花了一堆积分解决了
- 感觉越来越不经用了，经常出现二三十积分的消耗，一天才100积分

修改简述：

- Config/UI/UIPreset_View.gd（新增）：**角色数据看板**预设——一块 3/4 屏面板（`size_ratio` + `OpenAt.CENTER`）按 2 行 3 列矩阵摆六个一览，`CELL_CHARS` 按格宽反推每栏字数、每格 `margin` 4
- Config/UI/UIPreset_Status / Attr / Interaction / Skill / Shortcut / Archetype.gd（删除）：六个独立一览预设取消，外壳统一并入 UIPreset_View 的矩阵格子
- Config/SystemConfig.gd：新增全局底图 `ui_background` / `ui_background_slice` 与全局默认字色 `ui_font_color_default`（浅底深字，一处生效）
- Config/UI/UIPreset_Keyboard.gd：键盘底图改用全局默认（不再各自写 `background` / `background_slice`），注释同步
- Config/UI/UIPreset_Test.gd：测试窗底图说明同步（默认底图全局化）
- Script/Utils/Enums.gd：`OpenAt` 新增 `CENTER`（开在屏幕正中）
- Script/UI/UISystem.gd：新增 `screen_size()`——UI 坐标下的屏幕尺寸（`size_ratio` 定尺寸与 `CENTER` 摆位共用，取视口可见矩形并保证非 0）
- Script/UI/Interact/UIInteract_OpenClose.gd：`open` 支持 `OpenAt.CENTER` 摆位；示例注释从 Status 换成 RoleData
- Script/UI/UI/UI_View.gd（新增底座）：一览通用骨架——一条一段（`_section`）、默认收起、展开才建 `items`、实时订阅、只重铺那一段（`_refresh_section`）；六个一览共用
- Script/UI/UI/UI_Status.gd / UI_Attr.gd / UI_Interaction.gd / UI_Skill.gd / UI_Shortcut.gd / UI_Archetype.gd：改为 `UI_View` 钩子式一览（只回答"看谁/铺什么/订什么"），摆进看板六格；快捷一览改"一条一段 + 展开出输入框"
- Script/UI/UI/UIBase.gd：①`_fit_size`——收起（`collapsed`）时宽高都让给内容（窗口缩成标题文本宽）；**挂在容器（Container）里的元素不再自己写 `size`**，只报 `custom_minimum_size`（修"自写尺寸与容器分配打架"的排版振荡）②`_config_size` 支持 `size_ratio`；③`_make_background` / `_apply_background`：没写 `background` 的面板统一套全局默认底图
- Script/UI/UI/UI_Panel.gd：`_apply_background` 覆写——所有面板（含嵌套的格子/段）都套默认底图；**嵌套面板的竖向滚动条常驻**（`SCROLL_MODE_SHOW_ALWAYS`，斩断"滚动条出现/消失 → 可视区宽变 → 折行变 → 内容高变"的双稳态振荡，修看板开着就 signal 11 闪退）
- Script/UI/UI/UI_Label.gd：`fill_width`（顶满容器、自己那份宽仍算最小宽）与 `_keep_min_width`；`resized → _refit` 跟随折行重算高度；宽没定时先按一行报（修"一行文字变一列高塔"）
- Script/UI/Interact/UIInteract_Fold.gd：可折叠标题 / 段构造器调整（标题 `fill_width` 顶满、段标题限宽），配合收起宽度与看板格子
- Script/UI/UI/UI_Editor.gd：适配一览骨架的小改
- Script/UI/UI.md：同步 底图全局化 / 收起宽度 / 容器孩子不自写尺寸 / 嵌套面板滚动条常驻 等设计说明
- Script/Character/Status/Skill/Archetype/SystemShortcut 的 .md：四个一览的"在哪看、怎么开"条目改为看板入口
- Script/Character/Attribute/Attributes.gd、Interaction/InteractionPreset.gd：注释里的"想看它长什么样"指向改为看板
- Script/System/test.gd：演示改为开 RoleData 等新预设（调试探针已清理）
- Script/更新日志.md：清空旧条目（本轮重写）
