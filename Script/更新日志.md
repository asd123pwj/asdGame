## 0.26.17 指令系统统一为类python函数

- 指令系统之前有两套使用方式，一套为`Class.func(param1)`，一套为`Class.func param1`
  - 现在统一为前者，使用方式类似python函数
- 去掉了`$`，它原先用于指示这个值不是字符串，而是类/实例等
  - 现在字符串需用`""`框起，像常规代码里的字符串一样，因此没框起的自然就是正常的函数
  - 同理，UI系统里的也一并去掉了，现在直接用`self`和`event`就能指示当前状态
- 去掉了`&`，它原先用于指示要取值
  - 末尾是`)`意味着它调用的函数，返回函数值
  - 反之则意味着它是值，直接返回值
- 此外，依然支持对字典使用dict.key，对列表使用dict.key_list[0]的写法
- 这套比之前的清晰了不少，不错

### 改动 · 指令系统复查（去重 / 复用 / 补缓存）（Script/Command/CommandParser.gd、CommandSystem.gd）

- **参数值只剩一套编译**（`_compile_value`）：命令行参数、表达式参数、整行取值都走它 ⇒ 删掉 `_compile_value_expr` / `_compile_args`。顺手修两个 bug（只在**嵌套表达式**的参数位才触发，所以之前没露出来）：`Test.f(1, true)` 里的 `true` 被当类名去查（整个调用变 null）、`Test.f([1, 2])` 里的数组变成了字符串 `"[1, 2]"`。
- **`read` / `write` 共用路径处理**：抽 `_split_path`（整条路径编译成一个表达式计划，`write` 只把最后一步摘出来当赋值目标）⇒ 原来三份"kind → 宿主"的分派只剩 `_run_expr` 一份；函数参数与方法参数共用 `_run_arg_plans`。
- **补缓存**：`_path_cache`（路径 → 计划；`Utils.write`/`swap` 反复发同一批路径串）、`_line_cache`（整串 → 非空行，`split_lines`）、`CmdSys._all_sources`（源表：脚本 + 命令前缀，`_lazy_load` 不再每次全扫）、每命令 `arg_index`（参数名 → 下标，O(1)）；`_build_args` 加"全位置参数"快路。
- **清死代码 / 冗余**：`_convert_literal` 的引号剥离与重复判定、`_find_top_level_paren`（等价于 `find("(")`）、括号不配平时的 `rfind(")")` 兜底、`parse` 的 `"NOCOMMAND"`、`_type_zero`（并入 `_coerce`）。
- **保留**：私有方法（`_` 开头）照常注册为命令（有意为之，删掉了原来注释掉的那段过滤）。
- 复跑（`--headless`）无脚本错误；探针实测：`Utils.swap` 走字典键路径对调、表达式参数里的 `true` / `[1, 2]`、同一路径二次写入（命中 `_path_cache`）都正常。

### 顺手 · 老转义清理与指令串引号约定

- **删掉 `\` 与 `\$` 两处老转义**（`CommandParser`）：`_normalize_path` 不再剥前导反斜杠、`_convert_literal` 不再把 `\$` 还原成 `$`——路径本来就是"带引号的字符串"参数，不需要再叠一层转义；相关注释（`read` / `write`、`Utils.gd`）同步。
- **指令串外层统一用单引号**（Godot 和 Python 一样两种引号都行）：里面要写双引号（路径 / 字符串参数）时不必再写成 `\"`，写出来就是指令本身的样子（`UIPreset_Menu.gd` / `UIPreset_Test.gd` 里那些 `\v` 链）。
- **文档 / 注释对齐新写法**：`Script/UI/UI.md`（指令表里的 `open`/`close`/`toggle`/`drag` 签名、`open <宿主> CloseButton <宿主>`、`$取值链`、`--close_on_move` 这类旧叙述）、`Script/Command/Command.md`（`execute` / `parse` / `_compile` / `_tokenize` 段按新形态重写）、`Script/设计文档.md`、`Interact/UIInteract_OpenClose.gd` / `UIInteract_Edit.gd` 的指令示例、`Config/UI/*` 的注释（`--close_on_move`、`--preset_name`、手写 `\$`）。
- `UIInteract_SwapConfig.gd` 的空壳文件删掉（退役后已无人引用），并把 `.godot/global_script_class_cache.cfg` 里的陈旧类缓存重扫掉。

### 改动 · 指令统一成"一行 = 一个表达式"（Script/Command/CommandParser.gd、CommandSystem.gd、全仓配置与文档）

- **命令 = 函数调用**：`类.静态方法(参数, 名字=值)`。参数一律包在 `()` 里，逗号分隔。
  - 位置参数按签名顺序；**`名字=值` 可以跳过中间那些带默认值的参数**（像 Python 的关键字参数），没写的参数用签名里的默认值。
  - **没有 flag 语法**：bool 参数直接写 `名字=true`（原来的 `--close_on_blur` ⇒ `close_on_blur=true`）。
  - 例：`UIInteract.open(self, "Menu", self, close_on_blur=true)`、`MapSys.place(layer_id=0, x=10, force_space=true)`。
- **取值不再需要 `&`**：一行就是表达式——末尾带 `()` 就"调完拿返回值"（`self.refresh("content")`），不带 `()` 就取这个值本身（`Test.int1`、`self.control.text`、`5`、`"abc"`）。忘写 `()` 时取到的是函数本身，解析器会**警告一声**（原来会静默调用）。
- **参数的字符串用引号**：`Utils.write("self.config.content", 值)`——引号里的 `$` 不会被当成取值式（原来靠"顶层引号/手写 `\$`"两个规则，现在统一成引号一种）；**数组字面量**支持 `[a, b, c]`（可嵌套）。
- 参数组装（`CmdSys._build_args`）改成"位置参数按序落到空槽 + `名字=值` 落到对应槽 + 其余取默认值"；位置参数写在命名参数之后、名字不存在、参数给重了都会 `push_warning`。
- 删掉了旧的解析路径（空格分词 `_tokenize`、`--名字/--flag`、`&` 前缀兼容分支、`\` 与 `\$` 老转义）；`$` 前缀保留但可写可不写，UI 侧（`self`/`event` 两个词）已不再用。
- 全仓配置、代码、注释、文档里的指令串**一次性迁移**到新写法（`Config/UI/*`、`Config/Character/Archetype/*`、`Config/QuickName.gd`、`Script/System/test.gd` 等；迁移用一次性脚本跑，手改的点：拼接字符串那种）。

### 新增 · UI 输入框与编辑（Config/UI/UIPreset_Test.gd、Script/UI/UI/UI_Input.gd、Script/UI/Interact/UIInteract_Edit.gd、Script/Input/InputSystem.gd、PointerDetect.gd）

- `UI_Input`（LineEdit）：`config["content"]` 是初值（`refresh` 时写进框里，正在编辑时不回写），回车提交 → 派发 `QName.input_submit`。
- **元素里没有任何特判**：不连引擎信号，也不写死"点它进编辑"——那是配置里一条普通事件 `[QName.mouseLeft, 'UIInteract.begin_edit(self)']`，换事件触发也行。
- 编辑状态记在 `InputSys.edit_ui`：编辑期间按键**不进状态层**，**只有回车例外**——翻成项目自己的 `QName.input_submit` 派给正在编辑的输入框，于是"回车提交"也走在唯一输入链路上。
- `UIInteract.begin_edit` / `end_edit`（新文件 `Interact/UIInteract_Edit.gd`）+ `InputSys.end_edit()`；"点别处退出编辑"由 `PointerDetect.key` 开头顺手收掉。
- 提交 = 配置里一串普通命令：写目标的 `config.content` → 清空自己 → `end_edit` → 刷新改过的两个 UI（**顺序不能反**：编辑中的输入框跳过刷新）。

### 新增 · `UIInteract.toggle` 与两种"关掉"（Interact/UIInteract_OpenClose.gd）

- `UIInteract.toggle(target, preset_name)`：**显示着就关、否则开**（绑一个键做"按一下开、再按一下关"）。
- 关闭行为两个 bool，**都在 `open` 那一句给**：`close_on_blur`（点关）、`close_on_move`（移开关，hover 展开的子菜单挪开就收）；候选表 open 登记、close 摘掉。
- `reset_position()` 换成显式的 `refresh("position")`。

### 新增 · 通用指令 `Utils.write` / `Utils.swap`（Script/Utils/Utils.gd）

- `Utils.write("<路径>", <值>)`：通用"按路径写值"（宿主写在路径里；实例成员 / 字典键 / 列表下标 / 函数头都行）。**只改数据、不刷新界面**。
- `Utils.swap("<路径A>", "<路径B>")`：对调两条路径上的值——开关式按钮的底座（原来那条 `UIInteract.swap_config` 退役，`UIInteract_SwapConfig.gd` 已删除）。

### 改动 · 显示内容不再挂成员变量（UIBase / UI_Label / UI_Scroll / UI_Image / UI_Input）

- `UIBase.content` **删除**：内容就是 `config["content"]` 这一份数据，子类 `refresh(key)` 读它刷到控件。
- 不做"写 config 自动刷"：`config` 是 Dictionary、拦不住写入；换成带 `_set/_get` 的对象要把所有读点都改一遍，不划算。
- 刷新规矩：**改了什么刷什么** ⇒ `self.refresh("content")`；不传 key 才是全刷（当前全刷只多一次 `visible` 判断；`position` 必须显式传 key）。全刷也**不做**"old config 比较"（实测只在白刷时省 ~5.7µs/UI，值真变时反而多花，还要处处同步快照）。

### 修正 · 带空格的字典键（实测结论，写进 UI.md）

- 路径参数写成字符串时，**引号会保护键里的空格**：`Utils.write("self.config.带 空 格", 值)` 可以；取值那一侧写 `self.config.带 空 格`（`$` 路径是原样交给解析器的，空格不会被切）。
- `self.dict."带 空 格"` 这种"给键加引号"的写法**不支持**（引号会变成键名的一部分）；`.get("键")` 也不行（字典不是 Object，取值链的方法分支只认 Object）。

### 顺手 · 注释 / 文档与旧写法对齐

- 清掉 `$parent` / `$text` / `set_content` / `swap_config` / `UIInteract.refresh` / `on_edit` / `reset_position` / `send_to_bind` 这些旧写法与旧指令串：`Script/UI/UI.md`、`Script/设计文档.md`、`Script/Input/Input.md`、`Script/Auto/Auto.md`、`Script/Utils/Utils.gd`、`Script/System/BaseClass.gd`、`UIInteractBase.gd`、`UIInteract_SwitchValue.gd`、`UIInteract_SwapConfig.gd`、`UIPreset_Basic.gd`、`UIPreset_Test.gd`。
- `Script/UI/Interact/UIInteract_Content.gd` 删除（改内容 = 写 config + 刷新，不需要专门交互）。
