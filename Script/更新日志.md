## 0.26.28 文本框/编辑框的最大行数/最大字符数

- 最大尺寸换成了最大行数和最大字符数
- 修复UI显示区域和可交互区域不一致的问题

### 更新内容

- **字体：默认换成系统里的等宽文楷**（`Config/SystemConfig.gd` 的 `ui_font_names` ＋ `Script/UI/UISystem.gd` 的
  `apply_default_font`）
  - 挂**两处**才生效（实测：只挂一处都盖不住引擎默认主题）：**根窗口的主题**（`default_font` ＋ 按类型逐条
    `set_font("font", 类型, …)`，类型表见 `UISystem.FONT_TYPES`）＋ **控件级覆盖**（`UIBase.reapply` 里
    `add_theme_font_override("font", UISys.ui_font)`）
  - 为什么不能只设 `ThemeDB.fallback_font`：那是"主题链里一个字体都没有"时的兜底，而引擎默认主题**自己带字体**，
    兜底轮不到它（实测字体还是 `Open Sans`，中文靠逐字回退凑出来，宽窄比也就不是 2:1 了）
  - 系统里没装 ⇒ **什么都不换**（保持引擎默认）＋ 提醒一次：不报错、不中断启动
  - 实测：多行框与文字元素都拿到 `LXGW WenKai Mono`；步进 `0 / i / W = 10px`、`中 = 20px`（严格 2:1）
- **新增：宽度上限**（`UIBase._max_width_px` / `_half_width`，`UI_Label` 与 `UI_Input` 共用一套）
  - `max_chars`（**字符数**，中文算 2；单位取"半角与 全角÷2 里较大的那个"）与 `max_width`（像素），两个都写取小的
  - **配了就自动换行、宽度就等于上限**（短内容也不缩——同一栏要对齐）；不配就还是"宽 = 内容本身"
  - 高度：`UI_Label` 按折行数（优先用引擎按当前宽度报的最小高，见 `_text_height`）；`UI_Input` 多行 = 行数 × 行高
    ＋ 上下内边距
  - 修：`_create_control` 那一帧 `control` 还没赋值 ⇒ 上限要问"刚建的那个控件"，否则整条路都不生效（实测踩过）
- **输入框：`max_height`（像素）改成 `max_lines`（最多显示几行）**（`Script/UI/UI/UI_Input.gd`）
  - 行高 = 字高 ＋ 主题行距（量出来的）；`max_lines` 封顶，超出框内滚动（竖滚动条自己出来）
  - 修："刚好两行却冒出滚动条"——旧的高度公式少算了 TextEdit 的上下内边距（实测 2 行要 72、它给 68，差 4px）
- **只读文字也能定宽换行**（`UI_Label`）＋ 一览统一宽度（`UI_View._chars()` + `SysCfg.ui_view_chars = 48`）
  - `UIInteract_Fold.title_item(标题, 收起, chars)` 多了第三个参数；`UI_View.add_child_element` 覆写给铺出来的
    文字行**统一补上限**（漏一处就有一个长标签把面板撑开：实测漏过 `Count`「共 N 条…」和 `Note`）
  - `UI_Shortcut` 的输入框不再写死 340px，与同块的标签走同一个字符宽度
  - 实测：六个一览面板宽度**统一 528**（= 48 字符 × 10px ＋ 边距），最宽子元素都是"段"= 496 = 上限本身；
    段标题折 1 / 2 / 3 行、高度 28 / 55 / 82 与引擎一致
- **撤掉"尺寸网格"**（曾经"尺寸吸 32、间距吸 8"，写给九宫格切图用）
  - 冲突点：一行文字 28px 吸到 32 就多出小半行空白；面板宽固定成格子数则长行被裁
  - `SysCfg.ui_grid` / `ui_gap` / `snap_size` / `snap_size_up` **删除**；`UIBase._config_size` /
    `UI_Panel._scroll_cap` 直接读配置；`UI_Panel.MARGIN_SIZE` 回到普通 `const (16, 16)`
- **面板不再写死宽度**（一览的 `size[0]` 去掉、`scroll` 写 `[0, 上限高]`）：写死宽会把长文案裁掉
  （`clip_contents` 一裁，"长文字显示到一半就没了"）
- **顺带**：`UI_View._brief` 的截断 48 → **160** 字符（以前正好等于一栏宽：长值既被截又被折，白丢信息）；
  `UI.md` 的"面板宽度 / 一栏宽度"两节；清理陈旧注释（`min(最宽那行的字宽, 上限)`、"见旧注释"、写死的"一行 28px"）
  与 3 处多余的 `max_chars`
- 验证：探针实测——字体名 / 步进宽 / 行高、框高、折行数与引擎**逐条对上**，六个一览同宽、无内容超出面板、
  `max_lines` / `max_chars` 越界时滚动条如期出现；`--headless --editor` 全项目解析 clean、`--headless` 跑起来
  无脚本错误；另自动扫过一遍"定义了但全树只出现一次"的私有函数 = **0 个孤儿**
